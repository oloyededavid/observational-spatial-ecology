## Findings

| Finding | Evidence | Status |
| :--- | :--- | :--- |
| The 2024 forest raster is simulated | `code/afi_crossriver_corridor_analysis.ipynb`, cell 3: if the 2024 raster has no forest pixels, a loss mask built from edge distance and `np.random` (seed 42) overwrites `forest_2024.tif`. The stored output says "forest_2024.tif successfully updated". The branch was in the first commit | The fragmentation results (32 to 186 patches, +481.2%, mean patch area 9,448.89 to 1,607.53 ha, -83.0%) are withdrawn |
| The slope term of the resistance surface is synthetic | Cell 8 builds elevation from a formula (`150 + 450*x/nx + 200*sin(...)`). No elevation data is loaded. The report says it uses terrain slope | The corridor and resistance results are withdrawn |
| The corridor endpoints are raster fractions | Cell 8 places them at fixed fractions of the raster, then labels them Afi Mountain Wildlife Sanctuary and Cross River National Park | Not the protected areas |
| The report differs from the notebook output | Notebook against PDF: 2024 CAI 96.76 against 95.76; effective mesh size change -2.3% against -40.9%; mean resistance 4.41 against 12.40; peak resistance 16.22 against 108.50; tortuosity 1.24 against 1.26 (the README also says 1.26) | The PDF cannot be cited |
| The 2000 baseline is implausible | The effective mesh size and total area imply the 2000 forest mask covers at least 98.7% of the raster. With an all-zero real 2024 export, this points to a faulty Earth Engine export | Not verifiable without the rasters |
| The report's loss claim contradicts its own data | The simulated 2024 forest removes about 1.1% of the area, while the report says canopy loss was about 15% of the regional surface | |
| The notebook cannot run top to bottom | Cell 5 uses variables defined in later cells, and every execution count is empty | |
| Path length ignores diagonal steps | Cell 5 uses `len(path) * pixel_size` on an 8-connected path, so length and tortuosity are underestimated | |
| Claims without data | "Accelerating fragmentation", "agricultural pinch-points", "riparian corridors" and "monoculture farming and road access" rest on two dates and no land-use, river or road data. There is no validation against gorilla occurrence, telemetry or a published corridor map | |
